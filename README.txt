JULIE LOVE WEBPAGE ♡

HOW TO OPEN
1. Extract this ZIP file.
2. Open the julie_love_webpage folder in VS Code.
3. Open index.html in your browser (or use the Live Server extension).

ADD YOUR PHOTOS
Put your photos inside the images folder and use these exact filenames:
- you-and-julie-1.jpg
- you-and-julie-2.jpg
- you-and-julie-3.jpg

You can use .png instead, but then update the matching filename in index.html.
The provided dreamy-pink-bird.png is used as the background art.

ADD MUSIC
Put a song you have permission to use in this project folder and name it:
music.mp3

NOTE ABOUT AUTOPLAY
Browsers commonly block autoplay with sound until the visitor interacts with the page.
The page tries to autoplay, but if the browser blocks it, press “Play our song”.
